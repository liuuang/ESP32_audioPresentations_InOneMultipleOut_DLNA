# ESP32 多房间音频分发系统（DLNA / 多音源 → N 从机）

全本地、可 DIY、软件定义的多房间同播（近似同步）：一台 ESP32-S3 主机负责拉流解码，通过 UDP 把音频分发到多台 ESP32-S3 从机，每台从机独立驱动 PCM5102 DAC 出声。可作为多房间背景音乐系统，也可插入电脑当 USB 声卡使用（v1.1 规划）。

## 定位

- **做什么**：一台主机解码分发，N 台从机同步出声；音源 = URL 电台 + DLNA（网易云/手机推流）
- **做到哪**：v1.0 收口中 —— 网页控制每从机音量/延迟、从机在线状态回报、诚实时间显示
- **不做什么**：不做成品零售、不做 AirPlay/蓝牙、不做 U盘 host、不做精确毫秒级同步（对外称"近似同步同播"）、不支持 15 台以上（设计上限 15，实测范围 3–5 台）

## MVP 范围表（v1.0）

| 项 | 状态 | 验收 |
|---|---|---|
| 音源 | URL 电台 + 网易云 DLNA | 各稳定出声 ≥30 分钟 |
| 控制 UI | 网页：播放/停止 + 每从机音量/延迟滑块 + 全静音 | 滑块可用、状态刷新 |
| 从机状态 | 心跳回报（在线/音量/延迟/出声/缓冲） | 网页实时显示，掉线变灰 |
| 时间信息 | 已播时长；有界流显总时长、无界流标"直播" | 不假装可拖动 |
| 同步 | 近似同步同播（缓冲水位延迟校准） | 相邻房间无撕裂；不做时间戳同步 |
| 文档 | 本 README + 接线图 | 可复现 |

范围外（明确不做）：AirPlay、蓝牙输入、U盘 host、多主机级联、混音、触屏、时间戳级同步、UAC2、成品零售。

## 架构

```
音源(URL电台/DLNA) → 主机 ESP32-S3 解码(MP3→PCM)
  → 单声道下混 + 6dB headroom → UDP 单播分发(:12346)
  → 从机 ESP32-S3: 环形缓冲(PSRAM 2MB) → 音量/延迟 DSP → I2S → PCM5102 → 音箱
控制面: 网页(:80) + DLNA/UPnP renderer + 控制通道 UDP(:12347)
```

模块化分层：lib/source（音源）、lib/distribute（分发）、lib/control（控制面）、lib/pcmbuf（缓冲）、lib/i2s_dac（驱动）。

## 快速开始

1. 复制 `src/config.example.h` 为 `src/config.h`，填 WiFi
2. 接线（从机 S3 → PCM5102）：GPIO21→BCK、GPIO19→LCK、GPIO20→DIN、GPIO47→SCK(MCLK)、5V→VIN、GND→GND
3. 编译烧录：主机 `master`，从机 `slave_s3`（PlatformIO）
4. 浏览器开 `http://<主机IP>/` 控制；手机网易云/任意 DLNA App 推流

## 已知限制（诚实声明）

- 多从机为"近似同步"（无时间戳同步），并排近距离可闻相位差属预期
- 电台/直播流无总时长，进度条语义为"已播时长"
- DLNA Seek 跳转不支持（http 流能力限制，文档化）
- 家庭 2.4GHz 局域网、实测 3–5 从机、尽力而为
